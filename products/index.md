# 产品

自然常量的产品均可免费使用。

| 产品 | 一句话 | 形态 | 平台 | 获取 |
|---|---|---|---|---|
| [zmux](/zmux/) | 为多 Agent 并行工作打造的终端 | 桌面应用 | macOS 14 及以上（Apple Silicon 与 Intel） | [下载](https://github.com/adongguo/zmux/releases/latest) |
| [zwork](/zwork/) | 面向云效的桌面 Agent 工作台 | 桌面应用 | macOS 12 及以上（Apple Silicon） | [下载](https://github.com/adongguo/zwork/releases/latest) |
| [zdash](/zdash/) | 云效工作项的终端看板 | 命令行工具 | macOS、Linux（Node.js 22.14 及以上） | `npm install -g @adongguo/zdash` |
| [zclaw](/zclaw/) | 以你本人身份在钉钉里代答的数字分身 | 本机常驻服务 | macOS（Python 3.10 及以上） | `pipx install dingclaw` |
