# 介绍

zclaw 是在你自己的 Mac 上常驻运行的钉钉数字分身。它以你本人的身份，在你不方便看钉钉时替你答复；你也可以在会话里召唤它去查证、整理，再把结果发回会话。

::: info 名称说明
zclaw 由 DingClaw 更名而来，更名仍在进行中。目前安装包名为 `dingclaw`，命令为 `dingclawd`，本站文档照实使用这些名称。
:::

## 工作方式

1. 每隔 3 分钟，zclaw 通过钉钉命令行工具 dws 拉取新消息。
2. 按规则筛选：单聊处理全部消息，群聊只处理 @你 的消息；你自己、机器人和黑名单里的人发来的消息一律忽略；默认只处理你还没读过、15 分钟以内的消息。
3. 把符合条件的消息交给你选定的命令行 Agent 生成回复，Agent 也可以判断这条消息不需要回复。
4. 以你的身份把回复发回原会话，每条消息都带 AI 代发标识。

任何一项前置检查不通过，这一轮就不拉消息、不调模型、不发送。详见 [安全与合规设计](/zclaw/guide/security)。

## 核心概念

| 概念 | 说明 |
|---|---|
| 分身 | 在你的 Mac 上常驻运行的 zclaw 服务，加载后台服务后由 launchd 在登录时启动，异常退出后自动拉起 |
| 人设工作区 | `~/.dingclaw/` 下的身份、语气、技能和人物说明，决定分身怎么说话、知道什么 |
| Agent | 生成回复的命令行 Agent，支持 Qoder CLI、Claude Code 和 Codex |
| 权限档位 | 普通档、白名单档和高权限档，决定一次回复能使用哪些工具 |
| 召唤 | 在会话里 @ 自己，让分身处理这个会话里等着的消息，或执行你附带的任务 |
| 分身模式 | `auto` 按规则回复全部命中的消息；`summon` 只处理你召唤过的会话 |
| 终端面板 | `dingclawd tui`，分诊未读、预览会话、起草回复，由你亲自接管 |

## 你会用到的能力

- **代答**：不方便看钉钉时，分身按人设先答复常见问题；需要核实或人工处理的问题，会如实说明而不是给出未经确认的结论。
- **召唤**：发 `@me` 让分身处理当前会话里等着的消息；发 `@me <任务>` 交给高权限档去查证、整理并回复。
- **终端面板**：五个视图分别是分诊、全部会话、时间线、未读和找我的，可以筛选、搜索、起草回复和切换分身模式。
- **黑名单与白名单**：按不可变钉钉 ID 管理，黑名单里的人不会收到分身的任何回复。
