# 更新日志

## 0.4.6

### 新增

- 群里召唤分身：同事在群里真实 @你，并写「分身」加任务时，以高权限档处理并把结果发进群里（`group_avatar_summon_enabled`，默认关闭）。
- 机器人名召唤：你 @ 指定的机器人名加任务，等同于 `@me` 加任务（`robot_summon_names`，默认为空）。
- 可选的持续任务：召唤后建立一张卡片，同一发起人的补充和纠正会合并后继续执行，也可以停止（`continuous_tasks_enabled`，默认关闭）。
- 支持 Codex 生成回复。
- 终端面板直接显示会话中的图片，点击后用系统查看器打开。
- 终端面板的五个视图和会话支持按 `r` 或 `⌃L` 主动刷新，保留草稿和阅读位置。

### 变更

- 召唤不再只认消息开头，@ 自己可以出现在消息的任意位置。
- 终端面板键位调整：命令面板支持 `:` 和 `⌃K`；`⌃F` 改为搜人开聊，跨会话搜索聊天记录改用 `s`；撰写框中 `⌃G` 打开外部编辑器，`⌃T` 让分身起草。
- 撰写框中超出宽度的正文自动折行显示。
- Agent 配置支持 `binary` 简写，按名称和档位自动选用内置模板。

### 修复

- 修复发送结果不确定时，对方消息上仍被标出「已回复」的问题；遇到明确限流时退避重试。
- 卡片进度更新暂时失败后可以恢复。
- 修复从通讯录或搜索打开的会话没有出现在「全部会话」中的问题。
