# 介绍

zwork 是面向云效的 macOS 桌面 Agent 工作台：在同一个窗口里查看工作项、浏览代码、评审合并请求和跟进流水线，并把具体工作交给 Agent 完成。

## 核心概念

| 概念 | 说明 |
|---|---|
| 工作区 | 对应一个工作目录，包含若干标签页，可以归档 |
| 标签页 | 对话、文件或差异，关闭对话标签页不会删除会话 |
| 会话 | 与 Agent 的一次对话，可以在会话列表中搜索和重新打开 |
| Provider | 生成回复的模型服务或命令行 Agent |
| 模式 | 自主、智能、手动、仅聊天，决定 Agent 调用工具前是否需要批准 |
| 工作台 | 云效模块：工作项、代码库、合并请求、流水线和制品库 |
| 自动化 | 配方、技能、定时任务和扩展 |

## 云效工作台

在「设置 → 工作台」连接云效后，导航栏会出现以下模块，每个模块都可以单独关闭：

| 模块 | 能力 |
|---|---|
| 工作项 | 按项目和迭代查看需求、任务和缺陷，支持看板与列表、评论，可以交给 Agent |
| 代码库 | 浏览代码库；绑定本地克隆后，可以离线浏览文件与差异，并把工作目录交给 Agent |
| 合并请求 | 评审、评论并合并与你相关的合并请求 |
| 流水线 | 查看运行历史、作业时间线与日志，按分支触发运行 |
| 制品库 | 查看制品仓库及其最新版本，默认关闭 |

对云效的写操作执行前会先请你确认。

## Provider

zwork 只列出在这台 Mac 上可以运行的 Provider：

- **命令行 Agent**：Claude Code、Codex、Qoder CLI、Cursor Agent、Copilot CLI、Amp 等。需要先在本机安装并登录对应工具。
- **模型服务**：Anthropic、OpenAI、Google、OpenRouter、Ollama、Amazon Bedrock 等，填写 API Key 或在浏览器中登录即可使用。

对话开始后仍可以切换模型，zwork 会先提醒你新模型需要重新读取对话、消耗更多 token。Claude Code、Qoder CLI 等无法接手已有对话历史的 Provider，在对话有了消息之后不再可选。

## 模式

| 模式 | 行为 |
|---|---|
| 自主（默认） | 自动批准工具调用，可以自由编辑、创建和删除文件 |
| 智能 | 按风险级别判断哪些操作需要你批准 |
| 手动 | 所有工具、扩展和文件修改都需要你批准 |
| 仅聊天 | 只与所选 Provider 对话，不使用工具或扩展 |

在「设置 → 聊天 → 模式」中切换。

## 你会用到的能力

- **工作区与标签页**：按目录组织对话、文件和差异标签页；关闭的标签页可以重新打开，画布布局把对话和文档排成横向滚动的列。
- **文件与更改侧栏**：在右侧浏览当前工作目录的文件树和变更文件。
- **状态提示**：工作区和标签页会显示 Agent 正在运行、等待输入、失败或已完成。
- **命令面板**：搜索并执行命令，快速跳转工作区、会话和标签页。
- **Vim 模式**：在「设置 → 聊天」中打开后，聊天输入框支持 Vim 按键，见 [快捷键](/zwork/reference/shortcuts#vim-模式)。
- **扩展与 MCP**：支持 stdio 与 Streamable HTTP 两种 MCP 服务器。
- **自动化**：管理配方、技能、定时任务和扩展，技能从 `~/.agents/skills` 等目录读取。
- **外观**：多套主题，可以跟随系统外观；界面默认英文，可以在设置中切换为简体中文。
- **XiYang 桌面伙伴**：默认关闭，开启后在桌面上陪伴你的对话。
- **可编程**：`zwork desktop` 命令行可以控制正在运行的 zwork，见 [命令行](/zwork/reference/cli)。
