# 快捷键

以下为 macOS 上的默认快捷键。与 zmux 共有的操作使用相同的按键，在两个应用之间切换时不用改变习惯。

所有快捷键都可以在「设置 → 键盘」中修改、停用或恢复默认，实际生效的按键以设置页显示为准。

## 全局

在系统任何位置都有效，即使 zwork 不在前台。

| 快捷键 | 操作 |
|---|---|
| ⌃ ⌥ ⌘ G | 把 zwork 窗口切到前台 |
| ⌥ ⌘ ⇧ G | 打开快速启动器 |

## 工作区

| 快捷键 | 操作 |
|---|---|
| ⌘ N | 新建工作区：命名并选择所在文件夹 |
| ⌘ 1–8 | 跳到导航列表中的第 1–8 个工作区 |
| ⌘ 9 | 跳到最后一个工作区 |
| ⌃ ⌘ ] | 下一个工作区 |
| ⌃ ⌘ [ | 上一个工作区 |
| ⌘ ⇧ R | 重命名工作区 |
| ⌘ ⇧ W | 归档当前工作区并切换到下一个；有任务正在运行时会先请你确认 |

## 聊天输入框

| 快捷键 | 操作 |
|---|---|
| Enter | 发送消息 |
| ⇧ Enter | 换行 |

### Vim 模式

在「设置 → 聊天」中打开「Vim 模式」后，聊天输入框支持 Vim 按键。这个开关默认关闭。

- 输入框获得焦点时处于插入模式。按 `Esc` 或 `⌃ [` 进入普通模式，输入框角落会显示当前模式（NORMAL、VISUAL、VISUAL LINE）和尚未完成的按键。
- 普通模式和可视模式下，输入框对打字只读：按键不会插入文字，也不会开始输入法组字。
- 在任何模式下，Enter 都会发送消息。
- 输入框失去焦点后再次获得焦点，会回到插入模式。

| 类别 | 按键 |
|---|---|
| 进入插入模式 | `i` `a` `I` `A` `o` `O` |
| 移动 | `h` `j` `k` `l` 或方向键，`w` `b` `e` `W` `B` `E`，`0` `^` `$`，`gg` `G`；可以加数字计数，例如 `3w` |
| 编辑 | `x` `X` `s` `S` `r` `J` `D` `C` `p` `P` |
| 操作符 | `d` `c` `y` 加移动，或 `dd` `cc` `yy` |
| 可视模式 | `v` 按字符选择，`V` 按行选择 |
| 撤销与重做 | `u` 撤销，`⌃ R` 重做 |

暂不支持文本对象（例如 `iw`）和 `.` 重复。`j` `k` 按文本中的换行移动，不按屏幕上的自动折行；复制和粘贴使用输入框内部的寄存器，不经过系统剪贴板。

## 列表与文件树

以下按键固定可用，不在设置中列出。

| 快捷键 | 操作 |
|---|---|
| ⌃ N / ⌃ P | 在命令面板、搜索面板和文件树中向下 / 向上移动 |
| ⌘ ↓ | 在文件树中打开选中的项目 |

## 自定义快捷键

- 在「设置 → 键盘」中点击「修改」后按下新的组合键，保存即可生效。录制时会区分 ⌘ 和 ⌃。
- 「选择工作区 1…9」和「选择标签页 1…9」按一组设置：录制时按下修饰键和 1 到 9 之间任意一个数字，这组快捷键会同时作用于 1–9。
- 新的组合键已经分配给其他操作时，zwork 会提示冲突；确认后，这个组合键会从原来的操作上移除。
- 全局快捷键修改后立即生效。修改其他快捷键后，设置页会提示需要重启：「命令面板与标签页」分组里的操作在窗口内立即生效，新建聊天、设置等菜单快捷键要重启 zwork 后才会更新。
- 从旧版本升级时，没有改动过的快捷键会自动迁移到新的默认值，你自定义过的快捷键保持不变。如果新的默认按键已经被你的自定义快捷键占用，这个默认值不会启用，zwork 会提示你到设置中检查。
