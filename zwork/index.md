## 适合谁

- 使用云效协作，同时在 Mac 上用 Agent 写代码、排查问题的开发者。
- 希望在一个窗口里完成看需求、读代码、评审合并请求，再把具体工作交给 Agent 的人。
- 同时使用多种 Agent 和模型，想统一管理会话与工作目录的人。

## 系统要求

macOS 12 及以上，支持 Apple Silicon。
