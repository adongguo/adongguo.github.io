# 常见问题

## 支持哪些平台？

macOS 12 及以上，支持 Apple Silicon。

## 为什么检查不到更新？

- 1.51.0 不会检查更新，请手动下载并安装一次新版本。
- 自动更新要求 zwork 位于「应用程序」文件夹，并且你对该文件夹有写入权限；直接从磁盘映像中运行时不会更新。
- 更新从 GitHub 获取。无法连接 GitHub 或请求被暂时限制时，请稍后在「设置 → 应用」中重试。

## Provider 列表里没有我装好的命令行 Agent？

zwork 只列出这台 Mac 上可以运行的 Provider。请确认对应工具已经安装、在终端中可以直接运行，并且已经登录，然后重新打开 Provider 列表。

## 为什么对话开始后不能切换到 Claude Code？

Claude Code、Qoder CLI 等 Provider 无法接手已有的对话历史，对话有了消息之后就不再可选。新建一个对话即可使用它们。切换到其他模型服务仍然可以，zwork 会先提醒新模型需要重新读取对话。

## Agent 会不会直接执行命令、修改文件？

默认的「自主」模式会自动批准工具调用。希望重要操作先经过你确认时，在「设置 → 聊天 → 模式」中切换为「智能」或「手动」；只想对话时选择「仅聊天」。

## 云效令牌会发给模型吗？

不会。个人访问令牌只保存在本机钥匙串中，用于访问云效 OpenAPI，不会进入对话。

## 关闭窗口后，zwork 为什么还在运行？

在 macOS 上关闭所有窗口后，zwork 会继续在后台运行，点击 Dock 图标即可重新打开窗口。按 ⌘ Q 退出。

## 终端里找不到 zwork 命令？

`zwork` 命令行位于应用包内，不会自动加入 `PATH`。链接方法见 [快速开始](/zwork/guide/getting-started)。

## 可以和 zmux 一起使用吗？

可以。在 macOS 上，两个应用共有的操作使用相同的默认快捷键，例如 ⌘ 1–9 切换工作区、⌘ P 搜索工作区。

## 收费吗？

zwork 免费使用。所连接的模型服务和命令行 Agent 按各自的规则计费。
