# 更新日志

## 1.53.0 — 2026-09-15

### 新增

- 新增当前工作区的标签页搜索面板和工作区搜索面板，支持键盘导航、模糊匹配和最近项；工作区搜索可以直接切换到其他窗口中已打开的工作区。
- 工作区和标签页会显示 Agent 正在运行、等待输入、失败或已完成；运行中的指示会遵循系统的减弱动态效果设置。
- XiYang 在 8:00–22:00 空闲时保持清醒，眼睛跟随鼠标指针；夜间空闲时入睡，每 15 分钟温和提醒休息，提醒可以推迟到早上。

### 变更

- 新建聊天会在当前工作区创建空白标签页，沿用工作区的默认设置并聚焦输入框；新建窗口使用单独的快捷键。已有的自定义快捷键保持不变。
- Provider 提供的思考过程在回合进行中保持展开并增量更新，较长的思考内容渲染更轻量。
- Codex 等 ACP 类 Provider 的进度和回复改为增量输出，取消也更及时。

### 修复

- 再次激活正在运行的 zwork 时，只恢复最近活跃的窗口，不会显示其他后台窗口。
- 较早回合中迟到的权限选择不会再批准后续回合。
- 只有在对话底部实际看到对应内容后，已完成的活动才会标为已读。
- 锁屏、睡眠和唤醒后不再补发休息提醒。

## 1.52.0 — 2026-09-15

1.51.0 不会检查更新，请手动安装一次 1.52.0，之后可以在「设置 → 应用」中更新。

### 新增

- 工作区支持会话归档、文件和差异标签页、文件与更改侧栏，以及把对话和文档排成横向滚动列的画布布局。
- 没有打开标签页的工作区会直接显示输入框，发送后即成为一段对话。
- 可以重新打开最近关闭的标签页，连同一起关闭的文件和差异；标签栏下方会提示重新打开或查看归档。
- 已开始的对话可以切换模型，切换前会提醒新模型需要重新读取对话；无法接手对话历史的 Provider 在对话有消息后不再可选。
- 从 GitHub 自动检查并在后台下载更新，只安装经过签名和 Apple 公证的更新包。
- 选择 Provider 时自动发现可用模型。
- 工作项的状态和类型筛选支持多选，并可以隐藏自动化入口。

### 变更

- 关闭标签页不再显示撤销提示，关闭的对话保留在归档中。
- 新聊天默认使用工作区的默认目录，没有设置时使用最近一次对话的目录。
- 命令行 Provider 在切换模型和思考强度时保持进程，流式显示思考过程和排队状态，取消回合时及时停止。
- 只提供这台 Mac 上可以运行的 Provider。

### 修复

- 看板中隐藏未纳入筛选的状态泳道。
- 草稿会被保留，窗口控制按钮不再与标题栏重叠。

## 1.51.0 — 2026-09-13

首个正式版本。

### 新增

- 云效个人工作台：工作项看板与列表、代码库与本地克隆、代码与差异、合并请求、流水线和制品库。每个模块都可以在设置中关闭，工作项和合并请求可以交给 Agent。
- 新增 Qoder CLI Provider。
- 新对话可以在聊天页切换 Provider 和模型，只提供这台 Mac 上可用的 Provider。
- 每个工作目录的工作区标签页在重启后恢复，侧栏支持会话搜索和状态筛选。
- 命令面板和会话快速跳转，快捷键可以自定义。
- XiYang 桌面伙伴，会跟随对话，并对注视、轻点、双击、长按和拖动做出反应。
- 通过 `zwork desktop` 命令行和 zwork-desktop 技能控制正在运行的应用。
- 合并请求参与者和工作项负责人显示头像，工作项卡片按阶段、类型和优先级显示颜色。

### 变更

- 界面默认语言为英文。
