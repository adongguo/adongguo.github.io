# 安全与隐私

本页说明各产品会在你的电脑上保存什么、是否连接外部服务。内容随版本更新；如果发现与实际行为不一致，请通过对应产品的反馈渠道告诉我们。

## zmux

### 数据保存在哪里

zmux 在本机运行，终端内容、会话快照和配置都保存在你的电脑上：

| 内容 | 位置 |
|---|---|
| 会话快照（窗口、工作区、面板布局与滚动缓冲） | `~/Library/Application Support/zmux/` |
| 编码 Agent 的会话映射（用于续接会话） | `~/.zmuxterm/` |
| 配置 | `~/.config/zmux/` |

### 外部服务

- **账号与在线服务**：不启用账号登录、设备配对或远程连接。
- **网页链接**：在系统默认浏览器中打开，zmux 不内置浏览器。

### 本机控制接口

- `zmux` 命令行通过本机的 Unix socket 与应用通信。
- 可以在设置中配置 socket 密码。
- `zmux hooks setup` 会为你已安装的编码 Agent 写入钩子配置，钩子只与本机的 zmux 通信，用于展示 Agent 状态和续接会话。

## zwork

### 数据保存在哪里

| 内容 | 位置 |
|---|---|
| 会话记录与云效操作记录 | `~/.local/share/zwork/` |
| 配置 | `~/.config/zwork/` |
| 运行日志，包括最近 10 次模型请求的明文记录 | `~/.local/state/zwork/` |
| 应用设置与界面日志 | `~/Library/Application Support/ZWork/` |

### 凭据

- 模型服务的 API Key 等凭据保存在系统钥匙串中。设置 `ZWORK_DISABLE_KEYRING` 后，改为保存在 `~/.config/zwork/secrets.yaml`。
- 部分 Provider 的登录令牌以文件形式保存在 `~/.config/zwork/` 下。
- 云效个人访问令牌只保存在本机钥匙串中，不会进入对话。

### 外部服务

- **云效**：只访问你在「设置 → 工作台」中填写的 OpenAPI 地址。对云效的写操作执行前会先请你确认。
- **模型服务**：对话内容发送到你选择的模型服务或命令行 Agent，按其各自的隐私政策处理。
- **更新**：从 GitHub 检查和下载新版本，可以在「设置 → 应用」中关闭自动下载。
- **扩展运行时**：首次运行需要 Node.js 或 Python 的扩展时，会从 GitHub 下载所需的运行时。
- **会话分享**：只有在你主动分享会话时，才会生成加密链接并通过公共 Nostr 中继传递。
- **使用数据**：不上报使用数据，没有崩溃上报。

### 本机控制接口

- 桌面应用启动的后端只监听 `127.0.0.1` 上的随机端口，连接需要每次启动时生成的密钥。
- `zwork desktop` 命令行通过本机的控制 socket 与应用通信，socket 和令牌文件的权限为 0600，令牌每次启动都会更换。

## zdash

### 数据保存在哪里

| 内容 | 位置 |
|---|---|
| 配置、焦点集与本地关联 | `~/.config/zdash/` |
| 运行日志 | `~/.local/state/zdash/zdash.log` |

编辑描述或评论时，临时文件写在系统临时目录中，权限为 0600，用完即删除。

### 凭据

- 令牌来自环境变量 `YUNXIAO_ACCESS_TOKEN`，或 `token_cmd` 命令的输出。zdash 不把令牌写入磁盘，也不写入日志。
- 工作目录里的 `.zdash.yaml` 不允许设置 `token_cmd` 等会执行命令的配置。

### 外部服务

- 只访问配置中的 `baseUrl`，即云效 OpenAPI。
- 不上报使用数据，不检查更新。
- 只有你在界面中明确执行的编辑才会写入云效；焦点集和本地关联只保存在本机。

### 日志

默认记录启动、退出和操作涉及的工作项编号，不记录令牌以及请求、响应的内容。

## zclaw

zclaw 以你本人的身份发送钉钉消息。它的发送门禁、召唤与权限分档见 [安全与合规设计](/zclaw/guide/security)。

### 数据保存在哪里

| 内容 | 位置 |
|---|---|
| 配置，权限为 0600 | `~/.config/dingclaw/config.json` |
| 人设工作区 | `~/.dingclaw/` |
| 状态数据库与运行日志，目录权限为 0700 | `~/.local/state/dingclaw/` |

状态数据库保存消息正文、任务、跳过原因和发送记录，用于去重、恢复投递和追溯。

### 凭据

- 不附带、不转存 dws 凭据，dws 的登录状态由 dws 自己管理。
- 各 Agent 的凭据由 Agent 自己保存。设置 `agent_config_home` 后，分身使用独立的 Agent 配置目录。

### 外部服务

- 通过 dws 访问钉钉，通过你选择的 Agent 访问模型服务。
- zclaw 本身不直接发起网络请求，不上报使用数据。

### 本机通知

启用发送后，zclaw 默认为收到的消息弹出 macOS 通知并显示消息摘录，通知内容可能出现在锁屏上。设置 `local_notify_body` 为 `sender_only` 时只显示发送人，设置 `local_notify_scope` 为 `off` 时关闭通知。
