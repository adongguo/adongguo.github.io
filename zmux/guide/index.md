# 介绍

zmux 是一款 macOS 终端，为同时运行多个编码 Agent 的工作方式设计：让你始终知道每个终端里正在发生什么，哪个 Agent 在等你回复。

## 核心概念

| 概念 | 说明 |
|---|---|
| 窗口 | 一个 zmux 窗口，左侧是工作区侧栏 |
| 工作区 | 侧栏里的一行，通常对应一个任务或项目，可以嵌套分组 |
| 面板 | 工作区内分屏得到的区域，可以左右或上下拆分 |
| 标签页 | 面板里的终端标签，可以继续开子标签页 |

## 你会用到的能力

- **通知**：Agent 或任何终端程序发出通知时，面板亮起通知环，侧栏显示未读标记，同时弹出系统通知。
- **Agent 状态**：安装钩子后，侧栏和 Agent 活动面板会显示每个 Agent 是在运行、等待输入还是已完成。
- **会话恢复**：退出时自动保存窗口、工作区、面板布局、工作目录和滚动缓冲；重新打开后还原，已接入钩子的 Agent 可以续接原会话。
- **可编程**：`zmux` 命令行和 Unix socket 可以创建工作区、分屏、发送输入、读取屏幕内容和发送通知。
