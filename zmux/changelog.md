# 更新日志

## 0.66.0 — 2026-09-10

### 新增

- 工作区可以标记五星重要度，分组内的成员可以按 Agent 状态排序。
- 画布新增列式排列、间距设置与视口控制条。
- 终端标签页菜单支持复制工作目录，新标签页可以沿用相邻标签页的名称。

### 修复

- 修复持久终端在启动拥塞、恢复取消和重新挂载时失联或丢失输入的问题。
- 修复 Agent 会话归属、工作区分组排序和首行移动的异常。

## 0.65.0 — 2026-08-31

### 新增

- 使用独立的应用标识、配置、socket 和命令行，通过经过公证的 DMG 分发，可以与其他终端同时安装。
- 新增嵌套子标签页，以及重命名、关闭、移动和分组级的右键菜单。
- 新增本地终端会话持久化（Beta），应用重启和版本更新后可以重新连接原有终端。
- 右侧栏新增 Agent 活动与 Git 变更面板，面板按钮和快捷键可以自定义。
- 新增 Quick Access、Running Agents 和统一的任务状态，运行中、等待输入和已完成的 Agent 更容易定位。
- 新增工作区外部链接与笔记，可以通过侧栏、命令面板、命令行和 socket 管理。
- 新增 ⌘ E 最近项目面板，可以从标签栏、快捷键和命令面板创建 Agent 会话，支持 Qoder。
- 文件预览支持语法高亮，并可以直接用 Vim 或 Neovim 打开。

### 变更

- 默认界面语言调整为英文。
- 侧栏字体、标题粗细、选中颜色、面板顺序与可见性可以配置，通知铃铛可以从标题栏直接跳转。
- 纯文本粘贴改走低延迟路径，大多数粘贴操作响应更快。

### 修复

- 修复恢复中的持久终端被误删、已删除的工作目录导致新标签页退出，以及 daemon socket 丢失后的恢复问题。
- 修复重新连接终端时历史通知和铃铛被重复触发的问题。
- 修复 Agent 输出超过 64 KiB 时读取阻塞，以及 Agent 状态在清屏、中断和等待输入后显示错误的问题。
- 修复侧栏首行无法拖动、展开相邻分组、多选颜色不一致和任务状态圆点显示错误的问题。
- 修复最近关闭标签页显示错误工作区、分组锚点丢失和子分组排序异常的问题。
- 修复版本更新后本地持久会话失联的问题。
