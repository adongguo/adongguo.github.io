# 快捷键

以下为默认快捷键。工作区、分屏和通知相关的快捷键可以在设置中修改；终端内的按键绑定读取 `~/.config/ghostty/config`。

## 工作区

| 快捷键 | 操作 |
|---|---|
| ⌘ N | 新建工作区 |
| ⌘ 1–8 | 跳到第 1–8 个工作区 |
| ⌘ 9 | 跳到最后一个工作区 |
| ⌃ ⌘ ] | 下一个工作区 |
| ⌃ ⌘ [ | 上一个工作区 |
| ⌘ P | 跳转到工作区 |
| ⌘ ⇧ W | 关闭工作区 |
| ⌘ ⇧ R | 重命名工作区 |
| ⌥ ⌘ E | 编辑工作区描述 |
| ⌘ B | 显示或隐藏侧栏 |
| ⌥ ⌘ B | 显示或隐藏右侧栏 |
| ⌘ ⇧ E | 切换右侧栏焦点 |

## 标签页

| 快捷键 | 操作 |
|---|---|
| ⌘ T | 新建标签页 |
| ⌘ ⇧ ] | 下一个标签页 |
| ⌘ ⇧ [ | 上一个标签页 |
| ⌃ Tab | 下一个标签页 |
| ⌃ ⇧ Tab | 上一个标签页 |
| ⌃ 1–8 | 跳到第 1–8 个标签页 |
| ⌃ 9 | 跳到最后一个标签页 |
| ⌘ W | 关闭标签页 |

## 分屏

| 快捷键 | 操作 |
|---|---|
| ⌘ D | 向右分屏 |
| ⌘ ⇧ D | 向下分屏 |
| ⌥ ⌘ ← → ↑ ↓ | 按方向切换面板焦点 |
| ⌘ ⇧ H | 闪烁标记当前面板 |

## 通知

| 快捷键 | 操作 |
|---|---|
| ⌘ I | 打开通知面板 |
| ⌘ ⇧ U | 跳到最新未读 |
| ⌥ ⌘ U | 切换当前项的未读状态 |
| ⌃ ⌘ U | 把当前项标为最早未读并跳到下一条最新未读 |

「全部标为已读」和「清除全部通知」默认没有快捷键，可以在设置中绑定。

## 查找

| 快捷键 | 操作 |
|---|---|
| ⌘ F | 查找 |
| ⌘ ⇧ F | 在目录中查找 |
| ⌘ G / ⌥ ⌘ G | 查找下一个 / 上一个 |
| ⌥ ⌘ ⇧ F | 隐藏查找栏 |
| ⌘ E | 用选中文字查找 |

## 终端

| 快捷键 | 操作 |
|---|---|
| ⌘ K | 清空滚动缓冲 |
| ⌘ C | 复制选中内容 |
| ⌘ V | 粘贴 |
| ⌘ + / ⌘ - | 放大 / 缩小字号 |
| ⌘ 0 | 恢复默认字号 |

## 窗口

| 快捷键 | 操作 |
|---|---|
| ⌘ ⇧ N | 新建窗口 |
| ⌘ ⇧ P | 打开命令面板 |
| ⌘ ⇧ O | 重新打开上次的会话 |
| ⌘ , | 设置 |
| ⌘ ⇧ , | 重新加载配置 |
| ⌘ Q | 退出 |
