## 适合谁

- 在 macOS 上同时运行多个编码 Agent，需要随时知道哪个在等你的开发者。
- 习惯按任务组织终端，希望工作区、分屏和标签有清晰层次的人。
- 想用脚本或 Agent 自动化终端操作的人。

zmux 是终端，任何在终端里运行的编码 Agent 都可以直接使用。

## 系统要求

macOS 14 及以上，支持 Apple Silicon 与 Intel。
