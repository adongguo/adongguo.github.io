# 介绍

zdash 是云效工作项的终端看板：在终端里查看缺陷、需求和任务，按迭代跟进进度，直接编辑和流转状态。同一份数据也可以用 `--json` 或 `--plain` 输出，交给脚本和 Agent 使用。

## 视图

| 按键 | 视图 | 默认内容 |
|---|---|---|
| `1` | 缺陷 | 我的未解、我负责的、我提的、本迭代全部、全部未解 |
| `2` | 需求 | 我的未完成、我的进行中、本迭代全部 |
| `3` | 迭代 | 当前迭代的需求，按状态阶段分组，只看自己 |
| `4` | 焦点 | 你加入焦点的工作项，按需求、缺陷、任务分组 |
| `5` | 任务 | 我的未完成、我负责的、我创建的、本迭代全部、全部任务 |

缺陷、需求和任务视图由若干分区组成，每个分区是一组筛选条件，按 `h` / `l` 切换。分区可以在配置中自定义。

## 核心概念

| 概念 | 说明 |
|---|---|
| 分区 | 视图里的一个列表，由筛选条件定义，例如「我的未解」 |
| 迭代视图 | 左栏是迭代，右侧是分组列表；可以按负责人过滤、显示缺陷，或切换成按阶段分列的看板 |
| 焦点 | 本机维护的「我当前在处理什么」集合，按 `f` 加入或移出，不写入云效 |
| Profile | 一个配置文件里的多套组织与项目设置，用 `--profile` 切换 |
| 管道输出 | 标准输出不是终端时，zdash 输出 TSV；加 `--json` 输出 JSON |

## 你会用到的能力

- **预览**：按 `Enter` 或 `p` 打开预览面板，查看描述和详情；按 `C` 查看评论。
- **编辑**：按 `e` 修改状态、负责人、优先级、严重程度（缺陷）、迭代和数值字段，描述与评论在外部编辑器中撰写；按 `m` 直接流转状态。
- **筛选**：`/` 在当前列表中模糊筛选，按 `Tab` 升级为服务端查询；`F` 打开结构化过滤表单，按状态、负责人、项目、迭代等条件过滤。
- **多选**：按 `v` 标记多项，再按 `y` 复制编号、`Y` 复制链接，或按 `f` 批量加入焦点。
- **命令面板**：`⌃K` 列出当前工作项可用的操作和全局命令。
- **鼠标**：单击选中、双击预览、滚轮滚动；按住 `Shift` 可以交还终端进行文字选择。
- **自动刷新**：默认每 5 分钟刷新一次，终端重新获得焦点时也会刷新。

对云效的写入只会发生在你在界面中明确执行的编辑里，管道输出始终只读。
