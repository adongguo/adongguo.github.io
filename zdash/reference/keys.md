# 键位

在 zdash 中按 `?` 可以随时查看键位帮助。

## 通用

| 按键 | 操作 |
|---|---|
| `1`–`5` | 切换视图：缺陷、需求、迭代、焦点、任务 |
| `s` / `S` | 前进 / 后退循环切换视图 |
| `j` / `k`，`↓` / `↑`，`⌃N` / `⌃P` | 上下移动 |
| `h` / `l`，`←` / `→` | 切换相邻分区；迭代视图中切换迭代，看板中切换列 |
| `g` / `G` | 跳到首行 / 末行 |
| `Enter` | 打开预览面板 |
| `p` / `P` | 预览开关 / 切换预览位置（自动、右侧、底部） |
| `⌃D` / `⌃U` | 预览面板翻页 |
| `H` / `L`，`^` / `$` | 行内左右滚动 / 回到行首、行尾 |
| `r` / `R` | 刷新当前视图 / 全部刷新 |
| `?` | 键位帮助 |
| `q` | 退出 |

## 查看与编辑

| 按键 | 操作 |
|---|---|
| `o` | 在浏览器中打开选中的工作项 |
| `C` | 查看评论 |
| `e` | 编辑菜单 |
| `m` | 直接流转状态 |
| `f` | 加入或移出焦点；有标记时批量操作 |
| `v` | 标记或取消标记，用于多选 |
| `y` / `Y` | 复制编号 / 复制链接；有标记时复制全部标记项 |

`e` 编辑菜单中的字段：

| 按键 | 字段 |
|---|---|
| `s` | 状态 |
| `a` | 负责人 |
| `p` | 优先级 |
| `v` | 严重程度（仅缺陷） |
| `i` | 迭代 |
| `w`、`n` | 工作项类型中的数值字段，例如理想人天 |
| `d` | 描述，在外部编辑器中修改 |
| `c` | 新增评论，在外部编辑器中撰写 |

## 筛选与命令

| 按键 | 操作 |
|---|---|
| `/` | 在当前列表中模糊筛选；`Enter` 确认，`Tab` 升级为服务端查询，`Esc` 清除 |
| `F` | 结构化过滤表单，只在本次运行中生效 |
| `⌃K` | 命令面板：当前工作项可用的操作和全局命令 |
| `Esc` | 先清除标记，再清除筛选 |

`F` 过滤表单中的字段：`s` 状态（多选）、`a` 负责人、`p` 优先级、`v` 严重程度、`t` 类型、`l` 标签（多选）、`d` 创建时间、`o` 项目（多选）、`i` 迭代（多选）。

## 迭代视图

| 按键 | 操作 |
|---|---|
| `B` | 在列表和看板之间切换，看板按状态阶段分列 |
| `g` | 切换分组维度：状态阶段、负责人、类型 |
| `a` | 按负责人过滤 |
| `b` | 显示或隐藏缺陷 |
| `空格` / `za` | 折叠或展开光标所在分组 |
| `zo` / `zc` / `zs` | 展开 / 折叠 / 只展开当前分组 |
| `c` | 全部折叠或全部展开 |
| `zR` / `zM` | 全部展开 / 全部折叠 |
| `zj` / `zk` | 跳到下一个 / 上一个分组 |
| `[` / `]` | 看板中切换到上一个 / 下一个迭代 |

## 本地关联

启用 `links.enabled` 后可用。

| 按键 | 操作 |
|---|---|
| `O` | 打开工作项关联的 zmux 工作区；关联多个时进入选择面板 |
| `W` | 复制工作项关联的 worktree 路径 |

## 鼠标

| 操作 | 效果 |
|---|---|
| 单击 | 选中行或切换标签 |
| 双击 | 打开预览 |
| 滚轮 | 移动光标，或滚动预览与评论 |
| `Shift` + 拖动 | 交还终端，进行文字选择与复制 |
